# Changelog

## 0.1.0

- Group processes by application and show CPU, memory, disk I/O, and listening ports on Linux.
- Track local token usage for Claude Code, Codex, Pi, OpenCode, and Hermes. Show plan limits for Claude Code and Codex when available.
- Add eight built-in themes, custom TOML themes, and terminal background transparency.
- Provide prebuilt archives and SHA-256 checksums for Linux and macOS on x86_64 and arm64.
